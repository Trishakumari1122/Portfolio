# Trisha's Portfolio

A modern, responsive portfolio website showcasing projects, skills, experience, and certifications. Built with React, TypeScript, and Tailwind CSS.

## 🌐 Live Demo

[Visit the live portfolio](https://trisha-portfolio-vkmw.vercel.app/)

## 📋 Features

- **Responsive Design** - Fully responsive layout that works on mobile, tablet, and desktop
- **Dark Mode Support** - Modern UI with Tailwind CSS styling
- **Project Showcase** - Display of completed projects with descriptions and links
- **Skills Section** - Organized presentation of technical skills
- **Experience Timeline** - Professional experience and work history
- **Certificates** - Display of certifications and achievements
- **Contact Section** - Easy way to get in touch
- **Smooth Navigation** - Seamless scrolling between sections

## 🛠️ Tech Stack

- **Frontend Framework** - React 18 with TypeScript
- **Build Tool** - Vite
- **Styling** - Tailwind CSS + PostCSS
- **Component Library** - shadcn/ui
- **Package Manager** - npm / bun
- **Linting** - ESLint

## 🚀 Getting Started

### Prerequisites

- Node.js 16+ or Bun
- npm or bun package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Trishakumari1122/Portfolio.git
cd Portfolio
```

2. Install dependencies:
```bash
npm install
# or
bun install
```

3. Start the development server:
```bash
npm run dev
# or
bun run dev
```

4. Open your browser and visit `http://localhost:8080/`

## 🏗️ Build for Production

```bash
npm run build
# or
bun run build
```

The optimized production files will be in the `dist/` directory.

## 📦 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint to check code quality

## 🎨 Customization

### Styling

- **Tailwind CSS** - Configuration in `tailwind.config.ts`
- **PostCSS** - Configuration in `postcss.config.js`
- **Global Styles** - `src/index.css` and `src/App.css`

### Components

- Update component content in `src/components/`
- Use shadcn/ui components from `src/components/ui/`

### Configuration

- **Vite Config** - `vite.config.ts`
- **TypeScript** - `tsconfig.json`
- **ESLint** - `eslint.config.js`
